Arabic is an official language alongside Somali, which is the main everyday language. Skills should state which languages a product supports and when Arabic is the right choice.

## Good first skills

- `somalia-copy`: the product voice for Somalia, when to use the local dialect versus Modern Standard Arabic, and common UI terms.
- `somalia-product-ux`: phone numbers, addresses, currency display, payment methods, and messaging channels people actually use.
- `somalia-backend`: money, phone, and time-zone data, local providers, and privacy rules.
- `somalia-web-audit`: how to review a site or app for Somalia users.
